When you reply to a message, Cerb quotes the original content by default. This is designed to make it easy for you trim a few relevant lines from the original message to give context to your response[1](#fn:inline-replying).

However, many people just quote back your entire previous message in every response.

You can use the `#delete` command in a reply to quickly remove those huge blocks of quoted text.
