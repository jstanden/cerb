The REST-based[1](#fn:rest) Web API[2](#fn:api) provides the ability to remote control Cerb for automation, synchronization, and integration. For example, you can use the API from other applications and services to create tickets, search records, monitor notifications, manage tasks, and run automations.

The API uses [OAuth 2.0](/docs/api/authentication/) to authorize API requests. It supports returning data in XML or JSON.
