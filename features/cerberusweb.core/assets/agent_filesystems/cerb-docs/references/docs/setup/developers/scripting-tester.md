The Automation Scripting Tester is perfect for writing one-off scripts that don't warrant an entire automation.

## Access

The automation scripting tester can be accessed by clicking **Setup&nbsp;» Developers&nbsp;» Automation Scripting Tester**.

## Usage

You can write and run multiline scripts in the tester box. An example is using it for quickly transforming text.

 

You can also use [|json\_encode](/docs/scripting/filters/#json_encode) to quickly encode objects as JSON.
