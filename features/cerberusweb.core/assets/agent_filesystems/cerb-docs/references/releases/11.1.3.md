**Cerb (11.1.3)** is a **maintenance update** released on June 17, 2025. It includes **9** minor features and fixes from community feedback covering the [11.1](/releases/11.1/) update. You can [follow these instructions](/docs/upgrading/) to upgrade.

# Changelog

## Added

- **[Automations/LLMs]** In automations, added a new [llm.chat:](/docs/automations/commands/llm.chat/) command for single-turn chat completions without transcripts, memory, or tools. For instance, this is useful for text classification or summarization tasks.

- **[Connected Services/Packages]** In the package library, added a connected service for Google Gemini. This prompts for an API key to access AI APIs.

- **[Platform/LLMs]** Added a 'docker' LLM provider. This uses local model containers in Docker Model Runner.

- **[Platform/LLMs]** Added a [gemini](/solutions/integrations/gemini/) LLM provider. This uses Google's Gemini AI models.

- **[Records/Card Widgets]** On [card widget](/docs/records/types/card_widget/) worklists, added a filter for `record:` type.

## Changed

- **[Profiles/Widgets]** On profile widgets, added more practical examples for the `hidden@bool:` option.

- **[Plugins/UX]** Updated several plugin icons for consistent styling.

## Fixed

- **[Toolbars/Interactions]** Fixed an issue on [draft.read](/docs/toolbars/interactions/draft.read/) toolbars where interactions didn't trigger the common actions upon completion (e.g. alert, clipboard, search, snippet).

- **[Toolbars/Interactions]** Fixed an issue on [mail.read](/docs/toolbars/interactions/mail.read/) toolbars where interactions didn't trigger the common actions upon completion (e.g. alert, clipboard, search, snippet).
