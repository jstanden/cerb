**Cerb (10.4.18)** is a **maintenance update** released on July 11, 2024. It includes **6** minor features and fixes from community feedback covering the [10.4](/releases/10.4/) update. You can [follow these instructions](/docs/upgrading/) to upgrade.

# Changelog

## Fixed

- **[Dependencies/Smarty]** Fixed deprecation warnings from the Smarty template engine.

- **[Worklists/Export]** When exporting from a [worklist](/docs/worklists/), fixed an issue with date-based custom fields using the "human-readable dates" option always exporting as Unix timestamps.

- **[Profiles/Library]** On ticket profiles, fixed the 'Overview' package in the profile tab library. The 'Status' and 'Owner' widgets weren't current with the latest widget library.

- **[Mail/Reply]** Fixed an issue with Firefox 127.x where the clipboard text is replaced with 'undefined' after starting a ticket reply.

- **[Plugins/Versions]** Fixed an issue with displaying some plugins versions (e.g. 10.5 -\> 1.0.50).

- **[Files]** Fixed an issue with downloading filenames that contain spaces. The file extensions were being removed.
