**Cerb (11.1.8)** is a **maintenance update** released on April 16, 2026. It includes **6** minor features and fixes from community feedback covering the [11.1](/releases/11.1/) update. You can [follow these instructions](/docs/upgrading/) to upgrade.

# Changelog

## Changed

- **[Automations/Behaviors]** On events where automations and legacy bot behaviors are both triggered, automations with priorities 0-127 run _before_ behaviors, and automations with priorities 128-255 run _after_ behaviors. Previously automations always ran first. This affects the events: `mail.received`, `mail.sent`, and `record.viewed`.

- **[Performance/Worklists/Export]** Optimized bulk-loading of custom fields in worklist exports for better performance.

- **[Profiles/UX]** Added a more description 'Access Denied' error to profile pages when a worker lacks permission to view a record.

## Fixed

- **[Devblocks/Platform]** Suppressed repeated errors within a single request in the error handler.

## Security

- **[Security/Dependencies]** In response to security advisories, updated robrichards/xmlseclibs to 3.1.5+, phpseclib to 3.0.50+, and league/commonmark to 2.8.2+.

- **[Security/Dependencies]** In response to a security advisory, updated phpseclib to 3.0.51+.
