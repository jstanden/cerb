## Changed

- **[LLM/Providers]** Updated the Anthropic API Claude model IDs.

- **[Security/Dependencies]** Updated symfony/mailer to v7.4.12 in response to security advisory.

- **[Security/Dependencies]** Upgraded Twig to v3.27.1 in response to a security advisory.

- **[Security/Dependencies]** Upgraded phpseclib/phpseclib to 3.0.54 in response to a security advisory.

- **[Security/Dependencies]** Upgraded guzzlehttp/guzzle to 7.12.1 in response to a security advisory.

- **[Security/Dependencies]** Pinned all Composer dependencies to tested and audited versions.
