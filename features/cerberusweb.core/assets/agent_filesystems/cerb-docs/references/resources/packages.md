This functionality is now provided by [workflows](/resources/workflows/) in Cerb [11.0+](/releases/11.0/)

- [Chat Bot](/packages/chat-bot/)  
 A preconfigured bot with some helpful text-based conversational interactions. 
- [Dropbox Bot](/packages/dropbox-bot/)  
 A bot demonstrating integration between Cerb and Dropbox. 
- [Facebook Page Bot](/packages/facebook-page-bot/)  
 A bot demonstrating integration between Cerb and Facebook Pages. 
- [GitHub Bot](/packages/github-bot/)  
 A bot demonstrating integration between Cerb and GitHub. 
- [LinkedIn Bot](/packages/linkedin-bot/)  
 A bot demonstrating integration between Cerb and LinkedIn. 
- [Salesforce Bot](/packages/salesforce-bot/)  
 A bot demonstrating integration between Cerb and Salesforce. 
- [Saved Searches](/packages/saved-searches/)  
 A collection of preconfigured saved searches. 
- [Slack Bot](/packages/slack-bot/)  
 A bot demonstrating integration between Cerb and Slack. 
- [Stripe Bot](/packages/stripe-bot/)  
 A bot demonstrating integration between Cerb and Stripe. 
- [Twilio Bot](/packages/twilio-bot/)  
 A bot demonstrating integration between Cerb and Twilio.
